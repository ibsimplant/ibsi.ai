# ibsi.ai

Website of IBSI, the progressive-elasticity acetabular cup (patent pending IT 102026000028051).

Static site served by GitHub Pages at https://ibsi.ai

- `index.html` – the whole page (HTML, CSS and JavaScript)
- `models/implant.json` – 3D meshes of the shell, liner, head and stem (generic design geometry, no patient data)
- favicons, logo and `site.webmanifest`
- `CNAME` – custom domain for GitHub Pages

To update the site, replace `index.html` (and `models/implant.json` if the 3D model changes) and commit.
